# agent-eval

Lightweight evaluation harness for agent outputs, tool calls, and multi-turn traces.

## Scope

- Rubric-based scoring of agent outputs
- Golden-trace regression checks
- Structured result reporting
- Designed to stay small and local-first

## Status

Public from day one under hummbl-dev.

**No GitHub Actions workflows** are included by design to conserve Actions minutes on the hummbl-dev plan. Run tests locally.
